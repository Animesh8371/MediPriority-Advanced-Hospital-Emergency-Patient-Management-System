\# MediPriority — Phase 2 Project Description



Hospitals face significant challenges in managing emergency patients, doctors, beds, ICU facilities, ambulances, appointments, and medical records efficiently. MediPriority addresses these challenges through an integrated hospital management prototype that supports priority-based emergency handling and organized resource management.



The system combines Data Structures and Algorithms in C with Object-Oriented Programming in C++. A Min-Heap prioritizes emergency cases, a FIFO Queue manages appointments, Linked Lists maintain medical histories, Hash Tables support efficient patient lookups, and Graphs with Dijkstra’s Algorithm calculate shortest hospital transfer routes.



Phase 2 integrates a MySQL database, a C++ backend using the Crow framework, and a web frontend developed with HTML, CSS, and JavaScript. The database manages information about users, hospitals, doctors, patients, ambulances, appointments, beds, emergency cases, hospital routes, medical histories, and patient assignments.



Key features include patient record management, input validation, emergency triage, appointment handling, resource tracking, and hospital transfer route calculation. The development process includes data structure implementation, OOP development, database integration, API development, frontend implementation, and functional testing.



MediPriority demonstrates how algorithms, object-oriented design, database management, and web technologies can support hospital operations. It is an academic prototype using simulated data, not a production clinical decision-making system.
