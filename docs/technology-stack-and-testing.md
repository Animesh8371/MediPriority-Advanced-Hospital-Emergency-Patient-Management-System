\# Technology Stack and Testing



\## Technology Stack



\* \*\*Programming Languages:\*\* C and C++

\* \*\*Frontend:\*\* HTML, CSS, JavaScript

\* \*\*Backend Framework:\*\* Crow C++ web framework

\* \*\*Database:\*\* MySQL 8.0

\* \*\*Database Connectivity:\*\* MySQL Connector/C++

\* \*\*Data Structures and Algorithms:\*\* Min-Heap, Queue, Linked List, Hash Table, Graph, Dijkstra's Algorithm

\* \*\*Build System:\*\* CMake

\* \*\*Compiler:\*\* GCC/G++ with MinGW-w64

\* \*\*Development Environment:\*\* Visual Studio Code

\* \*\*Version Control:\*\* Git and GitHub

\* \*\*Additional Tools:\*\* Python for hospital data import and processing



\## Testing



The project includes C-based test suites for data structures and algorithms. Functional checks should cover emergency priority ordering, appointment queue operations, patient lookup, medical-history management, and hospital route calculations.



Database testing should verify schema creation, seed-data import, repository operations, and record consistency. Backend and frontend integration should be checked through the REST API and web interface.



Testing results should be recorded only after the corresponding tests have actually been executed. MediPriority is an academic prototype using simulated data and is not intended for real clinical decision-making.
